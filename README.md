## 주요 기능

| 기능 | 설명 |
| --- | --- |
| **한국어·영어 요약** | 화면 언어에 맞춰 웹페이지의 핵심 내용과 주의할 조건을 정리합니다. |
| **원문 근거 확인** | 요약 항목마다 근거가 된 원문 구절을 펼쳐 볼 수 있습니다. |
| **소리로 듣기** | 선택한 언어로 요약을 읽어 줍니다. |
| **읽기 설정** | 팝업과 사이드패널에서 글자 크기와 고대비를 조절할 수 있습니다. |
| **WCAG 접근성** | WCAG 접근성 기준을 반영해 키보드 탐색, 포커스 표시, 고대비 모드를 지원합니다. |

## Privacy Policy

- **Data sent** · When you request a summary, Easy Reader sends the text extracted from the current webpage and the selected summary language to its summary server. The text may contain personal information if it appears on the page.
- **Purpose and recipients** · The summary server sends the text to an LLM provider (Groq, NVIDIA, or Ollama Cloud) to generate the summary. If a request fails, the server may send the same text to the next configured provider.
- **Local storage** · Easy Reader stores the latest summary and your reading preferences in your browser. Uninstalling the extension removes this local data.
